# Portafolio de ingeniería

Contribuciones verificables de [jslponcev-ui](https://github.com/jslponcev-ui). Cada caso documenta el problema, la solución, las pruebas y la aceptación pública.

Solo se incluyen trabajos terminados, aprobados y fusionados. Este portafolio registra contribuciones técnicas; no representa una relación laboral con los proyectos.
